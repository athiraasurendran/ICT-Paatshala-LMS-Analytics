# Interview Notes: ICT Paatshala LMS Analytics

## 30-second explanation

During my IT Solution Internship in Data Science & Analytics at ICT Academy of Kerala, I worked on ICT Paatshala LMS Analytics. I used Python in Jupyter Notebook to prepare and analyse historical Excel-based data covering 2019–2025. Pandas and NumPy supported data preparation, while Matplotlib, Seaborn, and Plotly supported EDA and trend analysis. The analysis covered enrolment, dropout, course completion, learner engagement, assignment submissions, and programme performance. I also developed a Flask-based dashboard to present selected KPIs and trends. The underlying data and dashboard are confidential, so I share only a high-level case study.

## Problem context

Historical LMS information needed to be prepared and analysed to review learner engagement and programme performance across time periods and programmes.

## Approach

1. Reviewed the Excel data and available fields.
2. Used Pandas and NumPy for data cleaning and manipulation.
3. Performed EDA and descriptive statistical analysis.
4. Explored monthly and yearly patterns using Matplotlib, Seaborn, and Plotly.
5. Compared programme-level enrolment, completion, and dropout indicators.
6. Developed a Flask dashboard to present selected indicators and visualisations.

## Solution

A Flask-based dashboard that consolidated KPI cards and visual views for trends, learner activity, assignment submissions, engagement, and programme performance.
