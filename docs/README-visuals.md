# GitHub Visual Treatment

The main README uses GitHub-compatible Markdown tables, badges, collapsible sections, and Mermaid diagrams to make the case study easier to scan.

GitHub renders Mermaid diagrams directly in Markdown. Badge images are hosted by Shields.io and link to tool identities; if you prefer a fully offline README, remove the badge row from the main README.

No dashboard screenshot or fabricated chart is included because the original dashboard and underlying data are confidential.
